# 자가당착의 의미와 활용

**자가당착(自家撞着)**은 "스스로 한 말이나 행동이 앞뒤가 맞지 않고 모순되는 상황"을 의미하는 한자 성어입니다.

- **자(自)**: 자기, 스스로
- **가(家)**: 집, 자신
- **당(撞)**: 부딪치다, 충돌하다
- **착(着)**: 닿다, 일치하다

즉, **스스로 한 말이나 행동이 서로 충돌**하여 **모순되는 상황**을 나타냅니다. 이는 자기 모순에 빠져 **일관성 없는 주장**을 하거나, **앞뒤가 맞지 않는 행동**을 하는 것을 가리킬 때 사용됩니다. 자가당착은 논리적 일관성 없이 무언가를 주장하거나 변명하는 상황에서 자주 쓰이며, 자신이 만든 모순에 스스로 얽매인 상태를 비유적으로 표현합니다.
